# Node-RED Dashboard Setup Instructions

These steps help you set up the Node-RED dashboard for monitoring industrial motor sensor data from ESP32.

---

## 📦 Requirements

- Node-RED (https://nodered.org/)
- MQTT Broker (e.g., Mosquitto,emqx)
- ESP32 with sensors and firmware uploaded
- MQTT Dashboard nodes installed in Node-RED

---

## 🔧 Setup Steps

### 1. Install Node-RED
```bash
npm install -g --unsafe-perm node-red
node-red
